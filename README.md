# Science Compiler

`science-compiler` artifact experimenting with science-themed compilation / workflow UI, sharing `api-server` and `mockup-sandbox`.

## 💼 Real-World Use Case
Education or research-adjacent teams sketching interactive science workflows (labs, notebooks, checklists) without committing to a full LMS.

## 💰 Potential Value
- Monetizable only with a crisp vertical (e.g., HS lab workbook builder) and content partnerships.
- Demonstrates repeatable front-end packaging on the shared monorepo backend.

## 🚀 Demo / Access
Self-hosted / local only. Requires local Postgres and env configuration. No public demo URL.
